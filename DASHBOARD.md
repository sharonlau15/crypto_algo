# 📊 Crypto Strategy Dashboard

Interactive Streamlit dashboard for visualizing and analyzing cryptocurrency trading strategy performance.

## Features

### 📈 Overview Tab
- **Summary Metrics**: Aggregate Sharpe, CAGR, max drawdown, and win rate across selected strategies
- **Cumulative Returns Chart**: Visual comparison of strategy performance over time
- **Performance Metrics Table**: Detailed metrics (Sharpe, Sortino, CAGR, max DD, volatility, win rate)
- **P&L Summary**: Profit/loss analysis with initial/final capital, average daily P&L, best/worst days

### 🔍 Individual Analysis Tab
- **Strategy Drill-Down**: Select a single strategy for detailed analysis
- **Key Metrics Cards**: Sharpe, CAGR, max drawdown, win rate, Sortino, volatility, best/worst days
- **Performance Charts**:
  - Cumulative returns trajectory
  - Drawdown over time
  - Daily returns distribution (histogram)
  - Rolling 30-day Sharpe ratio
- **Monthly Heatmap**: Returns broken down by month for seasonal analysis

### ⚖️ Comparison Tab
- **Side-by-Side Charts**: Compare cumulative returns, drawdowns, and rolling Sharpe across strategies
- **Distribution Analysis**: Compare daily return distributions
- **Metrics Comparison Table**: Highlighted best/worst values across metrics

### ⚠️ Risk Analysis Tab
- **Drawdown Analysis**: Visualize underwater returns for all strategies
- **Rolling Volatility**: 30-day annualized volatility trends
- **Risk Metrics Summary**: Max drawdown, annual volatility, Sharpe, Sortino, VaR

## Installation

### Prerequisites
- Python 3.8+
- Backtest results already generated (run `python main.py --mode backtest` first)

### Setup

1. **Install Streamlit**:
```bash
pip install streamlit==1.31.1
# or install all requirements
pip install -r requirements.txt
```

2. **Run the dashboard**:
```bash
# Option 1: Using bash script
bash run_dashboard.sh

# Option 2: Direct command
streamlit run dashboard.py

# Option 3: In development mode (auto-reload on changes)
streamlit run dashboard.py --logger.level=debug
```

The dashboard will open at `http://localhost:8501` in your browser.

## Usage

### Getting Started

1. First, run a backtest to generate results:
```bash
python main.py --mode backtest
```

2. Start the dashboard:
```bash
streamlit run dashboard.py
```

3. Dashboard automatically loads all results from `results/` directory

### Navigation

**Sidebar Controls:**
- 📍 **Select Strategies**: Choose which strategies to display (multi-select)
- 👁️ **View Mode**: Switch between Overview, Individual, Comparison, and Risk Analysis
- ⏰ **Last Updated**: Timestamp of when data was last loaded

### Keyboard Shortcuts
- `R`: Rerun script (refresh data)
- `C`: Clear cache (force reload from disk)
- `Ctrl+C`: Exit dashboard

## Data Files Required

The dashboard reads from the `results/` directory generated by backtest. Required files:

```
results/
├── strategy_metrics.json        # All strategy metrics
├── portfolio_returns.csv         # Daily returns for each strategy
├── cumulative_returns.csv        # Cumulative returns
├── monthly_seasonality.csv       # Monthly performance data
├── regime_performance.csv        # Performance by market regime
├── attribution_report.csv        # Factor attribution
└── pnl_summary.csv              # P&L metrics
```

All these are automatically generated by `main.py --mode backtest`.

## Performance Tips

- **Dashboard is slow?** The dashboard caches data with `@st.cache_resource`. Press `C` to clear cache and reload fresh data.
- **Too many strategies?** Select fewer strategies in the sidebar to improve chart performance
- **Update results?** After running a new backtest, either:
  1. Refresh the browser (or press `R`)
  2. Press `C` to clear cache
  3. Restart the dashboard

## Customization

### Modify Colors

Edit the Plotly color scheme in `dashboard.py`:
```python
colors = px.colors.qualitative.Set2  # Change from Plotly default
```

Available schemes: `Plotly`, `Set1`, `Set2`, `Pastel1`, `Dark2`, etc.

### Add More Metrics

To add a new visualization:

1. Create a new plotting function:
```python
def plot_custom_metric(strategies):
    """Your custom chart"""
    # Your code here
    st.plotly_chart(fig, use_container_width=True)
```

2. Add it to the appropriate view mode in the main code

### Change Layout

Adjust the sidebar configuration:
```python
st.set_page_config(
    page_title="Your Title",
    layout="wide",  # or "centered"
    initial_sidebar_state="expanded"  # or "collapsed"
)
```

## Troubleshooting

### "No backtest results found"
**Error**: `No backtest results found. Run backtest first with python main.py --mode backtest`
**Solution**: Run backtest first:
```bash
python main.py --mode backtest
```

### Charts not displaying
**Cause**: Data loading failed or data files are empty
**Solution**: 
1. Verify results/ directory exists and contains CSV/JSON files
2. Clear cache: Press `C` in dashboard
3. Check console for error messages

### Dashboard is running slowly
**Cause**: Too many strategies or large data volume
**Solution**:
1. Select fewer strategies in sidebar
2. Clear cache with `C`
3. Reduce chart complexity by removing unused views

### Memory errors on large datasets
**Cause**: Loading too much data at once
**Solution**:
1. Filter to fewer strategies
2. Restart dashboard
3. Reduce rolling window sizes in risk analysis
